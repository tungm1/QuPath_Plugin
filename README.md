# QuPath_Plugin for CircleNet
This is the QuPath extension for glomeruli encircling with CircleNet, created by the Biomedical Data Representation and Learning Lab (HRLB) at Vanderbilt University.

This extension requires Java 17 (which is needed for any current Java QuPath plugin) and Python ~3.12.4.
Currently working on Ubuntu 20.04 and 22.04 (untested on other Linux distros), with work in progress for Mac and Windows compatibility in the future. It was designed for the QuPath 0.5.1, but may work for earlier versions.

# FIRST-TIME RUN INSTRUCTIONS:
Drag circlenet-extension-0.5.1.jar into QuPath to import it as an extension, and then simply go to extension and click "Run GLO Detection".
